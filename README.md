# advent of code 2025

My solutions to aoc '25!

## Challenge

I wanted to get better at C, so my challenge this year to do all problems in C :)

## Usage

Make sure you have `gcc` installed!!

### List all days that have solutions

```bash
make list
```

### Compile a specific day

```bash
make <day_number>
```

### Run a compiled day

```bash
make run DAY=<day_number>
```

### Remove all complied versions

```bash
make clean
```
